# 落地案例（Example）

> 本 skill 方法论在某教育领域"人才罗盘"项目完整落地：**table/ 30 页文档 + 数据库设计.md + db/ 全套产物（64 表 + 12 视图 + 9 张分域 ER 图）**。
> ⚠️ 案例中的业务名词（青年教师、师徒结对、师德师风、风险预警…）**仅为该项目业务，不是 skill 的约束**——把"教师"换成"客户/学员/设备/项目"等任何实体，流程完全一致。

## 案例结构（演示"方法论如何落成产物"）

```
talent_compass_hebust/
├── *.html                      # 31 个驾驶舱/工作台页面（含 page/ 子页、public/report/ 报告）
├── table/
│   ├── 00_数据表统筹总表.md     # 页面→表索引 + 8 域 61 表清单 + ER 链路 + 标准系统表 14 张
│   └── 01~30_<页面>.md          # 每页一档：图表清单总览 + 逐图口径 + 数据表字段定义
├── 数据库设计.md                # 事实表 50 + 系统表 14 = 64 表 + 12 派生视图 + 索引/同步策略
└── db/
    ├── talent_compass_schema.sql  # 全注释 DDL（COMMENT ON TABLE/COLUMN 全量）+ 种子数据
    ├── ER图.html / er/*.png       # 分域 ER 图画廊（9 张高清 PNG）
    └── ER图.dbml                  # dbdiagram.io 全量 64 表（在线导出 PNG/SVG/PDF）
```

## 案例中的关键决策（可直接复用）

| 问题 | 案例做法 |
|------|---------|
| 60+ 表一张 Mermaid 图画不漂亮 | 按 7 业务域分图；星型拓扑拆子图（成长域拆 2A/2B/2C）；每图 ≤10 表 |
| 页面口径从哪来 | 页面内置 `data-tip` 口径卡（数据来源/核算方法/设计目的），逐图引用 |
| 聚合指标不重复 | 全部 v_* 视图：v_growth_event（事实 UNION）、v_college_vitality、v_mentor_bearing… |
| FK 建表报错 | 先建被引用表（如 profile_tier 先于 pool_member） |
| 重名唯一约束冲突 | 允许"门类与明细同名"，唯一约束改为普通索引 |
| 视图布局丑 | 不画全量图；每域分图 + dbdiagram.io 兜底全量 |
