## 二、业务数据表总清单（按域分组）
### 域 1 · 基础档案域 BASE（主数据）
| 表名 | 用途 | 主键 | 关键字段 |
### 域 2 · 业务事实域（事件/流水，只追加）

## 三、表间关联关系（ER 核心链路）
```
base_{实体}（一实一档一码）
  ├─► {域}_fact*（业务事实）
  ├─► {域}_relation（关系，双向引用实体主键）
  ├─► {域}_input（资源投入）
  ├─► {域}_member（画像/梯队成员）
  ├─► {域}_warn（风险记录）
  └─► report_instance（报告快照）
```

## 四、标准系统表（sys_*）
| 表名 | 用途 | 关键字段 |
|------|------|---------|
| sys_user / sys_role / sys_user_role | 用户·角色·授权（data_scope 行级权限） | user_id、role_code、data_scope |
| sys_menu / sys_dept | 页面注册 / 组织机构 | menu_id、page_url、dept_id |
| sys_dict / sys_dict_item | 统一枚举字典 | dict_type、item_value、item_label |
| sys_config | 系统参数（权重/阈值/窗口系数） | config_key、config_value(JSON) |
| sys_log / sys_login_log | 操作/登录审计 | user_id、action、ip |
| sys_notice / sys_message | 公告/站内消息 | title、receiver_id、is_read |
| sys_file | 统一附件 | biz_type、biz_id、file_path |
| data_sync_log | 来源系统同步审计 | source_system、table_name、result |

## 五、派生视图清单（"不重复"的落点）
| 视图 | 计算来源 | 服务页面 |
|------|---------|---------|
| v_{实体}_view | 主数据 ∪ 最新状态 ∪ 当前关系 | 名单/台账类页面 |
| v_{域}_event | 各事实表 UNION（统一流水） | 时间轴/增量统计 |
| v_{域}_trend | v_*_event 聚合 | 趋势/多维对比 |
| v_{域}_bearing / v_{域}_eval | 关系+留痕计算 | 承载力/效能雷达 |
| v_{域}_vitality / v_{域}_index | 多表聚合 | 热力/均衡指数 |
| v_archive_dim | 各域完整性计算 | 档案完整度 |

## 六、口径统一
- 一实一档一码：业务主键全站唯一
- 维度编码统一：底层枚举进字典，页面"多维" = 字典映射投影
- 时间窗口一律由日期字段推导，不存周期列
- 每个图表指标可追溯到 表字段（页面"口径卡" → 字段映射表）
